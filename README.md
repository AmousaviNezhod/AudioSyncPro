# Audio Sync Pro

اکستنشن CEP برای Adobe Premiere Pro که سینک خودکار صدای کلیپ‌های انتخاب‌شده را انجام می‌دهد.

## ویژگی‌ها

- **سینک خودکار صدا**: با FFT و cross-correlation روی کلیپ‌های انتخاب‌شده محاسبه می‌کند و آن‌ها را هم‌زمان می‌کند.
- **توزیع خودکار روی ترک‌ها**: کلیپ‌ها را پس از سینک روی ترک‌های جداگانه قرار می‌دهد.
- **نرمالایز خودکار صدا**: میزان صدای هر کلیپ را با استفاده از `ffmpeg volumedetect` تحلیل کرده و Gain مناسب اعمال می‌کند.
- **رابط کاربری فارسی و RTL**: طراحی تیره و رسمی با تنظیمات FFMPEG و پارامترهای سینک.

## پیش‌نیازها

- Adobe Premiere Pro (CC 2018 به بعد پیشنهاد می‌شود)
- ffmpeg در مسیر `C:\ProgramData\chocolatey\bin\ffmpeg.exe` یا هر مسیر دیگری که در تنظیمات پنل مشخص می‌کنید
- CEP with Node.js فعال (در `CSXS/manifest.xml` تنظیم شده است)

## نصب

1. محتویات این مخزن را کپی کنید.
2. پوشه `AudioSyncPro` را در مسیر اکستنشن‌های Premiere Pro قرار دهید:
   - Windows: `C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\`
   - macOS: `/Library/Application Support/Adobe/CEP/extensions/`
3. اگر پنل باز نشد، در ویندوز کلیدهای `Win + R` را بزنید و `regedit` را اجرا کنید، سپس مسیر زیر را دنبال کنید و مقدار `PlayerDebugMode` را روی `1` تنظیم کنید:
   - `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` (یا نسخه متناظر CEP)
4. Premiere Pro را باز کنید و از منوی `Window > Extensions > Audio Sync Pro` پنل را باز کنید.

## استفاده

1. کلیپ‌های صدایی که می‌خواهید سینک شوند را در تایم‌لاین انتخاب کنید.
2. مسیر ffmpeg را در پنل بررسی کنید (اگر در PATH نیست، مسیر کامل را وارد کنید).
3. تنظیمات سینک (تأخیر حداکثر و دقت نمونه) و نرمالایز (هدف dBFS) را تنظیم کنید.
4. دکمه **شروع سینک** را بزنید.
5. پنل به صورت خودکار:
   - صدا را استخراج می‌کند،
   - آفست‌های زمانی را محاسبه می‌کند،
   - کلیپ‌ها را روی ترک‌های جداگانه منتقل می‌کند،
   - و Gain نرمالایز را اعمال می‌کند.

## ساختار پروژه

```
AudioSyncPro/
├── CSXS/manifest.xml      # مانیفست CEP برای Premiere Pro
├── index.html             # رابط کاربری فارسی/RTL
├── css/style.css          # استایل تیره
├── js/ui.js               # کمک‌کننده‌های UI
├── js/main.js             # کنترلر اصلی (CEP/Node bridge)
├── jsx/host.jsx           # ExtendScript bridge برای Premiere
├── libs/
│   ├── CSInterface.js     # کتابخانه Adobe CEP
│   └── Vulcan.js          # ارتباط بین پنل‌ها
└── node/
    ├── AudioUtils.js      # استخراج صدا، FFT، cross-correlation
    └── SyncEngine.js      # موتور سینک و نرمالایز
```

## نکات

- اولین کلیپ انتخاب‌شده به‌عنوان مرجع برای سینک استفاده می‌شود.
- در صورتی که صدای کلیپ شامل سکوت یا نویز بسیار زیاد باشد، دقت سینک ممکن است کاهش یابد.
- برای نتایج بهتر، قبل از سینک ابتدا صداهای ناخواسته را برش یا کم کنید.
