# Audio Sync Pro

اکستنشن CEP برای Adobe Premiere Pro که سینک خودکار صدای کلیپ‌های انتخاب‌شده را انجام می‌دهد.
موتور پردازش صدا و ffmpeg هر دو داخل خود پلاگین قرار دارند و نیازی به نصب Python یا ffmpeg جداگانه نیست.

## ویژگی‌ها

- **سینک خودکار صدا**: با FFT و cross-correlation روی کلیپ‌های انتخاب‌شده محاسبه می‌کند و آن‌ها را هم‌زمان می‌کند.
- **خوشه‌بندی هوشمند**: کلیپ‌های مرتبط را خودش تشخیص داده و آن‌هایی که قابل سینک هستند روی هم (در ترک‌های جداگانه) می‌چیند.
- **توزیع خودکار روی ترک‌ها**: کلیپ‌های مرتبط را روی ترک‌های جداگانه قرار می‌دهد.
- **کنار هم قرار دادن باقی‌مانده‌ها**: کلیپ‌هایی که هیچ سینکی ندارند بعد از گروه‌های سینک‌شده در یک ترک پشت‌سرهم قرار می‌گیرند.
- **نرمالایز خودکار صدا**: میزان صدای هر کلیپ را تحلیل کرده و Gain مناسب اعمال می‌کند.
- **رابط کاربری فارسی و RTL**: طراحی تیره و رسمی.

## پیش‌نیازها

- Adobe Premiere Pro (CC 2020 به بعد پیشنهاد می‌شود)
- ویندوز ۱۰/۱۱ (نسخه فعلی فایل اجرایی فقط ویندوز دارد)
- نیازی به نصب Python یا ffmpeg نیست (موتور و ffmpeg داخل پلاگین هستند)

## نصب

۱. کل محتویات مخزن را دانلود کنید و از حالت فشرده خارج کنید.

۲. پوشه `AudioSyncPro` را در مسیر اکستنشن‌های Premiere Pro کپی کنید:

```
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\AudioSyncPro
```

یا در مسیر کاربری:

```
%APPDATA%\Adobe\CEP\extensions\AudioSyncPro
```

۳. برای اجرای اکستنشن‌های امضا‌نشده (unsigned)، کلید رجیستری `PlayerDebugMode` را فعال کنید:

- کلیدهای `Win + R` را بزنید و `regedit` را تایپ کنید.
- مسیر زیر را باز کنید (اگر وجود نداشت بسازید):

```
HKEY_CURRENT_USER\Software\Adobe\CSXS.11
```

- یک مقدار `DWORD (32-bit)` با نام `PlayerDebugMode` و مقدار `1` بسازید.
- اگر Premiere شما نسخه ۲۰۲۴/۲۰۲۵/۲۰۲۶ است و کلید `CSXS.11` کار نکرد، همین کار را در `CSXS.12` یا `CSXS.13` هم تکرار کنید.

۴. Premiere Pro را کاملاً ببندید و دوباره باز کنید.

۵. از منوی `Window > Extensions > Audio Sync Pro` پنل را باز کنید.

## استفاده

۱. کلیپ‌های صدایی که می‌خواهید سینک شوند را در تایم‌لاین انتخاب کنید (حتی اگر همه روی یک ترک باشند).

۲. در صورت لزوم، مسیر `ffmpeg` را در پنل وارد کنید. اگر خالی بگذارید، پلاگین از ffmpeg باندل‌شده در `python/dist/bin/ffmpeg.exe` استفاده می‌کند.

۳. تنظیمات سینک و نرمالایز را تنظیم کنید:

- **نرخ نمونه‌برداری**: پیشنهاد ۱۶ kHz (مصالحه بین سرعت و دقت)
- **مدت نمونه**: تعداد ثانیه‌ای از هر کلیپ که برای تحلیل استفاده می‌شود
- **آستانه شباهت**: عددی بین ۰ تا ۱؛ کلیپ‌های با شباهت بالاتر در یک گروه قرار می‌گیرند
- **هدف نرمالایز**: میزان صدای هدف به dBFS (پیش‌فرض -۱.۰)
- **حداکثر آفست**: بیشترین تأخیر قابل جستجو به ثانیه

۴. دکمه **سینک و نرمالایز** را بزنید.

۵. پنل به صورت خودکار:

- صدا را از همه کلیپ‌ها استخراج می‌کند،
- کلیپ‌ها را بر اساس شباهت صدا خوشه‌بندی می‌کند،
- هر گروه سینک‌شده را روی ترک‌های جداگانه با شروع یکسان می‌چیند،
- کلیپ‌های بدون سینک را در یک ترک بعد از گروه‌ها قرار می‌دهد،
- و Gain نرمالایز را اعمال می‌کند.

## ساختار پروژه

```
AudioSyncPro/
├── CSXS/manifest.xml          # مانیفست CEP برای Premiere Pro
├── index.html                 # رابط کاربری فارسی/RTL
├── css/style.css              # استایل تیره
├── js/ui.js                   # کمک‌کننده‌های UI
├── js/main.js                 # کنترلر اصلی (CEP ↔ compiled engine)
├── jsx/host.jsx               # ExtendScript bridge برای Premiere
├── libs/
│   ├── CSInterface.js         # کتابخانه Adobe CEP
│   └── Vulcan.js              # ارتباط بین پنل‌ها
└── python/
    ├── dist/
    │   ├── sync_bridge.exe    # موتور سینک و نرمالایز (فایل اجرایی مستقل)
    │   └── bin/
    │       └── ffmpeg.exe     # ffmpeg باندل‌شده
    ├── sync_bridge.py         # نسخه توسعه Python
    └── requirements.txt       # وابستگی‌های Python (numpy) فقط برای توسعه
```

## نکات مهم

- پنل یک فایل `request.json` در پوشه `USER_DATA/AudioSyncPro` می‌نویسد، سپس `python/dist/sync_bridge.exe` را اجرا می‌کند و نتیجه را از `response.json` می‌خواند.
- اگر فایل اجرایی موتور کار نکرد، می‌توانید مسیر Python را در پنل وارد کرده و نسخه `python/sync_bridge.py` را اجرا کنید (`pip install -r python/requirements.txt` لازم است).
- حتی اگر همه کلیپ‌های انتخابی روی یک ترک باشند، عملیات سینک انجام شده و روی ترک‌های جداگانه قرار می‌گیرند (باید ترک‌های کافی در سیکوئنس وجود داشته باشد).
- در صورتی که صدای کلیپ شامل سکوت یا نویز بسیار زیاد باشد، دقت سینک ممکن است کاهش یابد.
- برای نتایج بهتر، قبل از سینک ابتدا صداهای ناخواسته را برش یا کم کنید.
