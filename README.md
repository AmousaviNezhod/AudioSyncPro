# Audio Sync Pro

اکستنشن CEP برای Adobe Premiere Pro که سینک خودکار صدای کلیپ‌های انتخاب‌شده را انجام می‌دهد. موتور پردازش صدا در Python اجرا می‌شود و از طریق `window.cep.process` با پنل CEP ارتباط می‌گیرد.

## ویژگی‌ها

- **سینک خودکار صدا**: با FFT و cross-correlation روی کلیپ‌های انتخاب‌شده محاسبه می‌کند و آن‌ها را هم‌زمان می‌کند.
- **خوشه‌بندی هوشمند**: کلیپ‌های مرتبط را خودش تشخیص داده و آن‌هایی که قابل سینک هستند روی هم (در ترک‌های جداگانه) می‌چیند.
- **توزیع خودکار روی ترک‌ها**: کلیپ‌های مرتبط را روی ترک‌های جداگانه قرار می‌دهد.
- **کنار هم قرار دادن باقی‌مانده‌ها**: کلیپ‌هایی که هیچ سینکی ندارند بعد از گروه‌های سینک‌شده در یک ترک پشت‌سرهم قرار می‌گیرند.
- **نرمالایز خودکار صدا**: میزان صدای هر کلیپ را با استفاده از `ffmpeg volumedetect` تحلیل کرده و Gain مناسب اعمال می‌کند.
- **رابط کاربری فارسی و RTL**: طراحی تیره و رسمی با تنظیمات Python، ffmpeg و پارامترهای سینک.

## پیش‌نیازها

- Adobe Premiere Pro (CC 2020 به بعد پیشنهاد می‌شود)
- Python 3.10 یا بالاتر همراه با `pip`
- ffmpeg در PATH یا مسیر آن در پنل مشخص شود (`C:\ProgramData\chocolatey\bin\ffmpeg.exe` یا هر مسیر دیگر)
- نصب وابستگی‌های Python:
  ```bash
  pip install -r python/requirements.txt
  ```

## نصب

1. محتویات این مخزن را کپی کنید.
2. پوشه `AudioSyncPro` را در مسیر اکستنشن‌های Premiere Pro قرار دهید:
   - Windows: `C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\`
   - macOS: `/Library/Application Support/Adobe/CEP/extensions/`
3. اگر پنل باز نشد، در ویندوز کلیدهای `Win + R` را بزنید و `regedit` را اجرا کنید، سپس مسیر زیر را دنبال کنید و مقدار `PlayerDebugMode` را روی `1` تنظیم کنید:
   - `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` (یا نسخه متناظر CEP)
4. Premiere Pro را باز کنید و از منوی `Window > Extensions > Audio Sync Pro` پنل را باز کنید.

## استفاده

1. کلیپ‌های صدایی که می‌خواهید سینک شوند را در تایم‌لاین انتخاب کنید (حتی اگر همه روی یک ترک باشند).
2. مسیر Python و ffmpeg را در پنل بررسی کنید (اگر در PATH نیستند، مسیر کامل را وارد کنید).
3. تنظیمات سینک (تأخیر حداکثر، دقت نمونه و آستانه شباهت) و نرمالایز (هدف dBFS) را تنظیم کنید.
4. دکمه **سینک و نرمالایز** را بزنید.
5. پنل به صورت خودکار:
   - صدا را از همه کلیپ‌ها استخراج می‌کند،
   - کلیپ‌ها را بر اساس شباهت صدا خوشه‌بندی می‌کند،
   - هر گروه سینک‌شده را روی ترک‌های جداگانه با شروع یکسان می‌چیند،
   - کلیپ‌های بدون سینک را در یک ترک بعد از گروه‌ها قرار می‌دهد،
   - و Gain نرمالایز را اعمال می‌کند.

## ساختار پروژه

```
AudioSyncPro/
├── CSXS/manifest.xml      # مانیفست CEP برای Premiere Pro
├── index.html             # رابط کاربری فارسی/RTL
├── css/style.css          # استایل تیره
├── js/ui.js               # کمک‌کننده‌های UI
├── js/main.js             # کنترلر اصلی (CEP ↔ Python bridge)
├── jsx/host.jsx           # ExtendScript bridge برای Premiere
├── libs/
│   ├── CSInterface.js     # کتابخانه Adobe CEP
│   └── Vulcan.js          # ارتباط بین پنل‌ها
└── python/
    ├── sync_bridge.py     # موتور سینک و نرمالایز
    └── requirements.txt   # وابستگی‌های Python (numpy)
```

## نکات

- پنل یک فایل `request.json` در پوشه `USER_DATA/AudioSyncPro` می‌نویسد، سپس `python python/sync_bridge.py request.json response.json` را اجرا می‌کند و نتیجه را از `response.json` می‌خواند.
- همه کلیپ‌ها با هم مقایسه می‌شوند و گروه‌های مرتبط به‌صورت خودکار شناسایی می‌شوند؛ مرجع هر گروه کلیپی است که بیشترین شبابهت را با دیگران دارد.
- حتی اگر همه کلیپ‌های انتخابی روی یک ترک باشند، عملیات سینک انجام شده و روی ترک‌های جداگانه قرار می‌گیرند (باید ترک‌های کافی در سیکوئنس وجود داشته باشد).
- در صورتی که صدای کلیپ شامل سکوت یا نویز بسیار زیاد باشد، دقت سینک ممکن است کاهش یابد.
- برای نتایج بهتر، قبل از سینک ابتدا صداهای ناخواسته را برش یا کم کنید.
